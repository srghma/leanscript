Two design points worth your attention. A computed field is recorded by the *type* of the cached value (a terminal type, as `hash` is a `UInt64`): the function that computes it lives in the term language, and a reference to it cannot be stored in `Ty`, since a global reference is typed by a signature which is itself a list of types. And its denotation is that of the base shape — a cached value is a function of the value, so storing it here would make a `Name` with the wrong `hash` writable; the cache decides the runtime object and hence the JavaScript, which is why the type language records it at all.
